# 图片 OCR 规范

## 适用范围

用于识别用户上传的营销需求截图，并将识别出的文字交给字段结构化流程。支持常见浏览器图片格式、简体中文和英文；不处理 PDF、视频或手写体保证。

## 运行规则

- 没有图片时跳过 OCR，直接识别手动输入文字。
- 最多处理 4 张图片，按上传顺序依次识别。
- 同一批图片复用一个 OCR worker，全部完成或失败后必须终止 worker。
- 开启自动旋转，保留有效换行，并清理零宽字符和无意义空白。
- 单张图片失败时继续处理后续图片；全部失败时才将 OCR 视为失败。
- 手动输入文字优先于 OCR 结果，OCR 只补充未明确提供的字段。

## 输出结构

`recognizeImages(images, options)` 返回：

- `text`：所有成功图片的文字，按上传顺序使用换行连接。
- `items`：每张图片的索引、文字、OCR 置信度或错误。
- `warnings`：无有效图片、部分图片失败或未识别到文字等提示。

`options.onProgress(event)` 可接收初始化、单图识别和完成进度，用于页面显示“识别中”状态。

## 隐私与依赖

当前浏览器实现使用 Tesseract.js worker 在用户设备上执行识别；首次使用需要加载 OCR 核心和中英文语言模型。不要把上传图片写入历史记录或发送到其他服务，除非用户之后明确授权接入外部 OCR 服务。
