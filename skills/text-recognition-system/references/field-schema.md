# 二级页面字段规范

## 输出结构

`extractDesignBrief(text)` 返回：

- `values`：已识别字段；没有可靠结果的字段不出现。
- `confidence`：各字段的 `high`、`medium` 或 `low` 置信度。
- `evidence`：各字段使用的原始文本片段。
- `warnings`：输入为空或信息不足等非阻断说明。

当输入来自图片时，先使用 `recognizeImages(images)` 获得 `text`。如同时存在手动输入，合并顺序为“手动输入文字 → 图片 OCR 文字”，确保用户明确提供的字段优先。

## 表单字段

| 字段 | 页面含义 | 支持值或格式 |
| --- | --- | --- |
| `title` | 主标题 | 原文短句 |
| `subtitle` | 副标题 | 原文短句 |
| `category` | 营销类别 | `本土节日弹窗`、`首页日常弹窗`、`营销氛围弹窗` |
| `offerType` | 权益 Offer | `单offer`、`双offer` |
| `copyOne` | 文案01 | 第一项权益说明 |
| `benefitOne` | 权益01 | 金额、折扣、免息、买赠等 |
| `copyTwo` | 文案02 | 第二项权益说明 |
| `benefitTwo` | 权益02 | 金额、折扣、免息、买赠等 |
| `buttonCopy` | 按钮文案 | CTA 原文 |
| `quantity` | 生成数量 | `1`、`2`、`3`、`4` |
| `quality` | 生成质量 | `High`、`Medium`、`Low` |

## 标签别名

- 主标题：`主标题`、`标题`、`headline`、`title`
- 副标题：`副标题`、`辅助标题`、`subheadline`、`subtitle`
- 营销类别：`营销类别`、`营销类型`、`弹窗类型`、`category`
- Offer 类型：`权益offer`、`offer类型`、`权益类型`、`offer数量`
- 两组权益：`文案01/02`、`权益01/02`、`第一/第二权益文案`、`第一/第二权益`
- CTA：`按钮文案`、`行动按钮`、`cta`、`button`
- 生成属性：`生成数量`、`生成质量`

## 推断规则

- 本土节日：春节、圣诞、万圣节、开斋节、斋月、排灯节、中秋、国庆等节庆词。
- 营销氛围：大促、限时、秒杀、狂欢、周年庆、会员日、新品、黑五、双 11、618 等活动词。
- 首页日常：首页、日常、常规、通用、daily、evergreen 等常态词。
- Offer：百分比、折扣、币种金额、满减、立减、免息、买赠等可核验权益。
- CTA：立即领取、马上购买、去使用、查看详情、Apply Now、Shop Now 等行动短语。

明确标签和明确的“单/双 Offer”表述优先于以上推断。
